## 确认的问题及修复

原来的 `right_gripper_present: false` 只移除额外夹爪电机、指尖及抓取负载；相机是独立负载。原配置仍对左右两侧各计入 `wrist_camera_kg: 0.12`，右侧质心设为 link7 坐标系 `(0,-0.08,0.04)` m。用户已确认右侧相机也已拆除，故这是实际结构与配置的明确不匹配。

新增 `left_wrist_camera_present` / `right_wrist_camera_present`，未提供时均默认为 true，兼容已有配置。当前配置为：

```yaml
left_gripper_present: true
right_gripper_present: false
left_wrist_camera_present: true
right_wrist_camera_present: false
wrist_camera_kg: 0.120000
```

零重力、标定、Quest follower、轨迹回放和离线模型均按对应侧相机安装状态计算。右侧额外相机质量为 0，左侧保持 0.12 kg；配置合并写入及“URDF 初值”操作均保留安装状态。修复后的右侧运行时原始 G(q) 在上述全部姿态中与不含额外负载的 CAD 模型一致。需停止并重新启动控制器使用新程序；本次未触发热加载或实机运行。

## 为什么恢复 URDF 初值不等于实机准确悬停

1. **按钮仅恢复部分模型参数。** `scripts/seed_gravity_comp.py` 将 link mass scale 设为 1、CoM delta 设为 0、逐轴 scale/bias 设为 1/0；相机、负载、远端经验增益和摩擦仍保留。它打印的 home 重力不是运行时完整前馈：打印使用 EE 质心 `(0.00645,0,0.1245)` m，未计相机，也未使用远端增益；运行时使用 `(0,0,0.1475)` m，并叠加相机及经验增益。当前机器没有 Pinocchio，打印采用解析后端；与 KDL 的基础重力符号已核对一致。
2. **实际前馈经过缩放。** 零重力采用 `ff_gain=0.95`，静止时即使 CAD 完全准确也只提供模型力矩的 95%；Quest/回放位置跟踪采用 `tracking_g_scale=1.08`。这两种模式不能用同一悬停手感判断。零重力 Kp 为 0，只有腕部轻微速度阻尼，因此残差不会被位置控制自动抵消。
3. **经验增益不代表一致的物理质量。** 当前相机逐轴增益 `[0.33,0.26,0.5,0.3,1.005,0.75,0.45]`，夹爪增益 `[0.285,0.15,0.45,0.15,0.36,1,1.1]`。例如同一末端负载在不同关节只补偿不同百分比，属于原有手感调节；恢复 CAD 质量后仍保留它们，会形成混合模型。右侧同时无夹爪、无相机后这两项额外力矩均为 0，左侧仍受影响。
4. **摩擦和实物参数仍有误差。** 库仑补偿采用 `Fc*tanh(k*dq)+Fv*dq`，符号随速度反向；当前 J4 Fc 为 0.4 Nm。若实机摩擦与该值不匹配，推上去和放下来手感可能不同。CAD 质量、质心与实物安装、线缆、零位的偏差也会随姿态变化。不能仅凭上抬/下坠就确定是哪一项，更不能用一个全局倍率同时修复所有姿态。

| --- | --- | --- | --- |
| J1 | 3.222 | 3.314 | 3.061 |
| J2 | 5.076 | 5.118 | 4.822 |
| J3 | 2.105 | 2.196 | 2.000 |
| J4 | 2.516 | 2.581 | 2.391 |
| J5 | -0.0568 | +0.0107 | -0.0539 |
| J6 | -0.2209 | -0.2241 | -0.2099 |

在 101 个右臂姿态中，误计相机使 J1..7 的原始模型力矩最大绝对变化分别约为 `[0.1305,0.1438,0.1585,0.0987,0.1037,0.0734,0.0206]` Nm。J5 在 home 甚至由负变正，说明小力矩腕轴会特别敏感；这些数值证明配置确实影响补偿，不证明它是全部实机症状的唯一原因。

还需注意：夹爪安装开关只扣除单独追加的质量，不会重写 link7 的 CAD 惯性，link7 仍约 0.466 kg。如果实际拆卸还移除了被 CAD 算进 link7 的支架/部件，必须根据拆卸部件的质量和质心进一步修正；不能无依据将整条 link7 质量归零。

## 右肩仍上抬的后续检查

用户后续确认主要测试右侧，问题集中在肩部。新日志 `gravity_20261012_191549.csv` 约 46.11 秒，每侧 2,306 条完整样本；应用日志确认加载当前配置、右侧夹爪额外质量为 0，稳定姿态下记录的 G(q) 与当前无右相机的离线模型一致。例如末条右侧 J2 记录 3.15931 Nm，离线复算 3.1593143 Nm，因此不能将本次现象解释为右侧相机开关没有生效。

当前右 J1/J2 仍为 scale=1、bias=0。右 J2 记录的总活动范围约 1.7823 rad，摩擦补偿最大约 0.0689 Nm；数据未标注手接触和松手时刻，不能把整段活动视为自主运动，也不能直接从它拟合肩部的正确重力倍率。当前材料支持继续检查肩部质量/质心、拆卸件是否包含在 link7 CAD 惯性内及零位偏差，尚不足以确认具体原因。

另发现零重力及标定器在加载 YAML、热加载和设置 tune 时会把显式为 0 的摩擦参数补回默认值，妨碍独立检查重力。本次删除这些覆盖；配置存在时原样使用摩擦参数，配置文件缺失时仍按原逻辑给默认值。启动日志增加每侧相机有效质量、肩部 scale/bias/Fc。未根据无手接触标签的拖动日志自动生成或部署新肩部倍率。

下一步可在“手动微调”中选择右臂，先单独检查 J2 的摩擦项和重力倍率；偏置保持 0，从当前倍率附近做小幅、可回退的调整，并在不同肩部角度复核。如果一个倍率在不同姿态无法同时减小漂移，应采集对应裸腕结构的软持静态标定数据，用现有基于运行时 KDL 的自动微调验证后写回。旧的自由拖动 CSV 缺少 `tau_g` 和标定增益等字段，不能作为可靠的自动精修输入。
