# 电机参数页实时关节角度

从控制台启动遥操作（仿真或真机）、零重力或拖动示教后，在“电机参数”页查看左右臂 J1～J7 的实测角度。每个关节同时显示弧度和度数，不包含夹爪。无需点击“读取电机参数”；该按钮仍用于 EEPROM 参数查询。

页面约每 100 ms 刷新，后台最多约 30 Hz 发送最新反馈。尚未接收时显示“无数据”，超过 0.5 秒未更新时显示“反馈超时”并隐藏旧角度。停止后不会继续把旧角度显示为实时值。页面可纵向滚动查看原有参数表。

MoveIt 的独立 ROS 控制路径尚未接入。空闲状态不启动 CAN 查询，不使能机械臂；当前功能显示已有运行进程的反馈。

## 控制周期

控制端复用已有的实测关节位置，不额外查询 CAN。通过固定大小快照交接给独立线程：控制线程使用 try_lock，缓冲区忙时直接跳过，不等待消费者。快照路径不分配堆内存，不编码数据、不写文件、不发网络。独立线程通过非阻塞本机 UDP 发送，只保留最新快照。

控制台绑定本机动态 UDP 端口，通过子进程环境变量 OPENARM_JOINT_ANGLE_PORT 传给控制程序。未设置此变量时不创建遥测线程，独立命令行启动的原有行为保持不变。

## 验证

- `cmake --build build -j 4`
- `QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -s tests -p test_joint_angles.py -v`
- `QT_QPA_PLATFORM=offscreen .venv/bin/python -m unittest discover -s tests -p test_console_qml.py -v`
- 双臂 MuJoCo 无窗口仿真确认左右臂各收到约 30 Hz、每帧七个关节值。

已验证接收、非法值拒绝、最新帧覆盖、超时及界面加载。零重力已编译，未运行真机；实际控制周期的 P99、最大值与超期次数仍需在目标硬件上对比验证。快照函数微基准不能代替控制周期测试。
