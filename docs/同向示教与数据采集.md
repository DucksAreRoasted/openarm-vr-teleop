# 同向示教与数据采集

## 模式与操作

在控制台选择“同向示教”：右臂为可徒手拖动的主臂，左臂为同向跟随臂，夹爪同向跟随。无需佩戴 Quest；柔顺零重力模式已移除。

1. 配置左右 CAN（默认左 can1、右 can0），确认急停和双臂运动空间。
2. 点击“启动”。右臂使用当前重力补偿，左臂从当前位置缓慢接入方向映射后的关节目标，不回零、不播放桌面轨迹。
3. 等待控制器就绪和左臂对齐，填写批次名，点击“开始录制”。
4. 单手拖动右臂及右夹爪；左臂及左夹爪自动跟随。慢拖，避免跟随滞后累积。
5. 点击录制区“停止”，再选“成功”“失败”或“重新录制”；“数据管理”可查看和导出。
6. 完成后点击“停止并释放”。双臂会失能，停止前应托住机械臂。

命令行入口：`./run.sh --mirror`（保留兼容参数名，当前执行同向映射）。首次使用需先配置 CAN；控制台会调用 CAN 配置程序。该模式不会启动 Quest 桥接，也不会接收 VR 或 TCP 点动指令。

## 同向映射与控制

采用关节空间方向映射：左右肩部前后摆臂 j1、腕部上下俯仰 j7 的转轴方向相反，需要同时反转角度和速度前馈；其余关节沿用同号映射。

| 关节 | 左目标相对右反馈 |
| --- | --- |
| j1 前后摆臂 | 反号，修正左右转轴方向 |
| j7 夹爪上下俯仰 | 反号，修正左右转轴方向 |
| j2～j6 | 同号，按左臂限位裁剪 |
| j8 夹爪 | 同号 |

已将 URDF 中七个转轴变换到身体坐标系核对，并验证多姿态下的末端位置增量及旋转变化：目标未被限位裁剪时，两臂做同向运动，末端间保持约 0.422 m 的侧向间距。j7 控制上下俯仰，j8 控制开合，二者映射不同。左右臂 j1、j2 行程不同；例如右 j2 大于约 0.1745 rad 时，左 j2 目标停在其上限。到限位后停止外向速度前馈，右臂返回左臂有效行程后恢复跟随。

右臂采用与普通零重力相同的质量、附件、倍率/偏置和摩擦配置；左臂在重力前馈上增加位置/速度跟随。两臂读取 `config/gravity_comp.yaml`，支持手动微调热加载，不修改 `inf.backup`。

控制周期 5 ms（200 Hz）。启动对齐阶段仍限制七关节为 0.35 rad/s、0.7 rad/s²，夹爪为 0.5 rad/s、1 rad/s²。对齐完成后日志显示 `TRACKING`，界面才开放录制；随动阶段限制提升为七关节 1.5 rad/s、6 rad/s²，夹爪 2 rad/s、8 rad/s²。

随动速度目标采用“右臂实测速度按关节方向映射 + 位置误差纠正”，不再只用 `2 × 位置误差` 慢追。持续匀速或加减速运动在上限内由速度前馈跟随，超过上限仍会限幅。此修改没有增加电机刚度或引入未经标定的惯性力矩前馈；真实左臂仍可能因负载、摩擦或力矩饱和产生跟随误差。

实际夹爪允许角度为 -0.98～0.62 rad，与当前 VR 夹爪默认行程一致。右夹爪手动输入在边界附近超出行程时，左夹爪目标钳制到此范围。右夹爪反馈速度保护阈值为 10 rad/s，左夹爪目标仍限制为 2 rad/s；夹爪位置增益为 6、阻尼为 0.45，总力矩仍限制为 1 Nm。七关节限位取 URDF。每秒输出 `[mirror][track]`，包含限位后目标误差、实测跟随误差、两臂/目标速度、左右夹爪实测位置与目标位置及最高控制周期，便于区分目标生成延迟与电机跟踪滞后。

夹爪独立跟随：目标最多领先左夹爪实测位置 0.2 rad，防止右夹爪快动或左夹爪受阻时参考持续积累。闭合时若目标领先、左夹爪低速持续 0.25 s，则视为疑似接触或阻力过大，改为接触位置前方 0.05 rad 的柔和保持（静止时弹簧力矩约 0.3 Nm，总力矩上限仍为 1 Nm）。这不是力传感器识别，无法单凭软件区分抓到物体与机械卡滞。右夹爪从闭合峰值回开 0.03 rad 后立即释放保持，按相对开合量打开；再次闭合或回到全开端后恢复绝对角度跟随。正常夹持或暂时滞后不再直接停掉双臂，通信、电机故障、反馈限位和非法下发仍会停机。夹爪不会阻塞七关节对齐后的录制就绪状态。

`[mirror][track]` 新增 `gripper_limited`（目标限差）、`gripper_holding`（疑似接触保持）、`gripper_left_effort`（实测力矩）；保持切入/释放另有 `[mirror][gripper]` 日志。CSV 中左夹爪动作记录限差/保持后的实际下发目标，右夹爪仍记录手动示教反馈。

右臂为手动输入，七关节反馈速度保护阈值为 4 rad/s；左臂为驱动跟随，仍为 2 rad/s。左右夹爪反馈速度保护阈值均为 10 rad/s。这些阈值用于检查反馈，不改变左臂目标限速：随动阶段仍为 1.5 rad/s、6 rad/s²。右臂运动超过左臂目标限速时，左臂会暂时落后；过大的跟随误差仍触发停机。

左臂七关节实测速度超过 0.8 rad/s 后，逐渐削弱沿运动方向的追赶力矩（含位置/速度 PD 和摩擦补偿），同时加入反向阻尼；到 1.5 rad/s 时取消沿运动方向的驱动力。先按关节力矩限额裁剪总力矩，再执行减速，避免大位置误差抵消限速作用。减速区间从 0.8 开始，以降低低惯量腕关节在 200 Hz 下因过陡制动产生的振荡。重力保持力矩作为基线保留，最终总力矩仍受原有关节限额约束。此措施可能降低高速追赶能力，不保证真机绝不超速；2 rad/s 硬停保护保持有效。每秒的 `[mirror][speed-guard]` 日志记录触发关节位掩码（最低位为 j1）和区间内左臂最高实测速度。

反馈超过 150 ms 未更新、电机故障、非有限数值、越界、反馈速度异常、七关节跟随误差超过 0.45 rad或控制周期超过 50 ms时停止并失能双臂。停机日志包含当前速度阈值和主/从臂角色。软件限位不包含自碰撞及环境碰撞检测。

## 数据与字段

沿用当前数据目录：`recordings/sessions/<批次>/<序号>/`。

- `real_teleop_split/left/`：左臂实际下发的限速目标，含夹爪。
- `real_teleop_split/right/`：右臂实测示教轨迹，含夹爪；右臂没有位置跟随弹簧，因此不能记录无意义的零位置命令。
- `real_teleop_dual_merged.csv`：合并后的双臂轨迹，可供现有回放工具读取。
- `lerobot_episode.csv`：约 30 Hz 的双臂实测状态和动作；观测为两臂反馈，动作为左臂限速目标与右臂实测示教姿态。
- `collection_mode.json`：记录 `right_master_left_same_direction` 模式、`[-1,+1,+1,+1,+1,+1,-1,+1]` 的关节方向及动作语义。
- `cameras/`、`outcome.txt`：沿用当前相机采集与结果标记流程。

原始分臂 CSV 约 200 Hz，LeRobot 样本仍约 30 Hz；数据顺序保持左 8 关节、右 8 关节。相机配置、导出和数据管理与 VR 遥操共用。相机是否接入及实际导出结果需在本机检查。

## 离线验证

```bash
.venv/bin/python -m unittest discover -s tests -q
OPENARM_MUJOCO_HEADLESS=1 timeout -s INT 5s build/quest_cartesian_control \
  --sim --mirror-teach --mirror-sim-demo --no-quest-ui \
  --urdf assets/v1.urdf --xml /path/to/scene_table.xml
```

`--mirror-sim-demo` 仅允许仿真，生成小幅右臂运动验证跟随；`--no-quest-ui` 关闭 UDP 录制入口。现有 MuJoCo 后端直接写入位置，适合验证方向映射和数据链路，不代表验证了真实电机的力矩稳定性。本次未运行真机，也未验证实体相机采集。
