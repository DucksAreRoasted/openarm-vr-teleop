# 动作录制与轨迹回放

也支持 OpenArm KER 录制的 V1 双臂片段，设备接入、映射标定及录制操作见 [KER 示教与回放](KER示教与回放.md)。

## Quest 遥操录制与回放

1. 运行 `./app.sh`，选择“仿真遥操”或“真机遥操”，按平常流程连接 Quest 并启动控制器。
2. 在“数据采集”填写批次名称，点击“开始录制”，用 Quest 操作双臂及夹爪。
3. 动作完成后点击“数据采集”中的“停止”，再标记成功或失败，保存本段动作。
4. 点击主控制区“停止并释放”，等待遥操控制器退出。
5. 点击“动作回放…”载入最近保存的片段，或在“数据管理”选中片段后点击“回放此条”。
6. 先使用默认的“仿真回放”和 0.5 倍速度检查轨迹。源数据单位按录制模式选择：真机录制用“真机夹爪角度”，仿真录制用“仿真夹爪位移”。
7. 仿真验证后，可选择“真机回放”，确认 CAN、急停和工作区条件，再点击“开始回放”。回放时无需 Quest 在线，控制器会自动驱动双臂及夹爪。

回放支持暂停、继续及停止释放；播放结束会保持末帧，点击“停止并释放”才退出。录制片段保存在 `recordings/sessions/<批次>/<序号>/`，回放窗口默认读取合并的双臂关节轨迹。

## 录制与回放

1. 在控制台选择“同向示教”，启动后等待对齐完成。
2. 点击“开始录制”，徒手拖动右臂及夹爪，左臂跟随；完成后停录并标注。
3. 点击主控制区“停止并释放”，托住机械臂，等待示教控制器退出。
4. 点击“动作回放…”：优先载入日志中最近保存的片段；也可从“数据管理 → 回放此条”载入选中片段。
5. 先选“仿真回放”检查动作，再选择真机、速度和源数据夹爪单位，点击“开始回放”。
6. 回放先从双臂实测位置慢速接入首帧，再自动播放。“暂停”会停止轨迹时间并保持首帧接入后的当前参考附近；“继续”接着播放。
7. 播完保持末帧。点击“停止并释放”退出控制器并失能双臂；关闭窗口也会先停止，不能绕过释放过程。

默认仿真、0.5 倍速度，另有 0.25 和 1 倍。真机使用控制台的左右 CAN 设置，默认左 `can1`、右 `can0`，接口须已通过控制台配置。回放窗口独占操作，不能与示教、遥操、零重力或标定同时启动。

## 轨迹与夹爪单位

支持片段目录（如 `recordings/sessions/批次/01`）及双臂合并 CSV。可选择文件/目录，也可拖入路径输入框。目录优先读取 `real_teleop_dual_merged.csv`；只有分臂 CSV 时临时合并，不修改录制文件。

CSV 按左 8、右 8 排列，列为 `time,q0,dq0,tau0,...,q15,dq15,tau15`，也接受不含 `tau` 的版本。Quest 遥操片段重放录制的双臂关节动作。同向示教片段中，右臂重放实测示教动作，左臂重放录制的下发目标；不再次应用同向映射。旧镜像片段也会重放原记录的双臂动作。

“真机夹爪角度”对应 −0.98～0.62 rad；“仿真夹爪位移”对应 0～0.044 m。跨仿真/真机回放会显式转换夹爪行程，必须按录制来源选择单位。

## 控制行为

使能前检查整段 CSV 的列、有限数值、递增时间和双臂位置限位，错误文件不进入硬件初始化。记录的力矩与速度不直接下发：位置插值生成速度，重力补偿按当前 `gravity_comp.yaml` 重算。

录制小数位舍入可能使关节位置略超 URDF 边界。七个臂关节仅容许不超过 `1e-6 rad` 的舍入偏差，并将内存中的位置收回精确边界；超过该范围仍拒绝回放，不修改源文件。日志会显示 `NORMALIZED` 数量。

控制频率为 200 Hz。接入首帧目标限速 0.3 rad/s、0.6 rad/s²；播放时七关节为 0.6 rad/s、1.2 rad/s²，夹爪为 1 rad/s、4 rad/s²。目标跟不上时冻结轨迹时间等待追赶，因此所选倍率是上限，实际播放时间可能更长。保留实测速度阻尼、2 rad/s 从臂超速保护、力矩上限、CAN 新鲜度与电机故障检查；夹爪沿用反馈限差和疑似接触柔和保持。

软件限位不包含碰撞检测。当前仿真后端直接跟随位置，能验证流程和数据，不能验证真机力矩稳定性。

## 命令行

```bash
# 仿真回放（默认 0.5 倍）
.venv/bin/python script/replay_teaching.py recordings/sessions/批次/01 --sim
# 离线检查，不使能电机
.venv/bin/python script/replay_teaching.py recordings/sessions/批次/01 --real --check
# 真机接口须已配置
.venv/bin/python script/replay_teaching.py recordings/sessions/批次/01 --real --speed 0.25
```

环境变量 `OPENARM_MUJOCO_XML` 指定仿真场景，`OPENARM_GRAVITY_YAML` 指定补偿文件。标准输入接受 `pause`、`resume`、`stop`；Ctrl+C 也会退出并释放双臂。

## 排查回放问题

窗口每次回放都会将启动参数、控制器输出、报错和退出状态保存到 `/tmp/openarm_teaching_replay_日期_时间_进程号.log`，路径显示在窗口日志首行，并写入控制台日志。可用 `ls -t /tmp/openarm_teaching_replay_*.log` 找到最近一次；关闭窗口后日志仍保留。
