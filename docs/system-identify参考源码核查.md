## 实际方法

1. **轨迹优化**：傅里叶参数化，使用 tanh 映射限制关节位置，差分进化粗搜索后进行约束局部优化。目标包含动力学或动力学加摩擦回归矩阵条件数；同时约束起始状态、速度和加速度。
2. **动力学回归**：`inertia_model.py` 使用 Pinocchio 的 `computeJointTorqueRegressor`，每个运动关节十个惯性参数。
3. **联合辨识**：`experiments/identify_params.py` 拼接惯性、摩擦和转子惯量回归子。摩擦包含平滑库仑与粘性项；外层优化摩擦过渡速度，内层求解带 URDF 先验的正则化最小二乘。按关节力矩 RMS 归一化。
4. **加速度处理**：由反馈速度中心差分，再做 Savitzky–Golay 滤波；指令加速度用于对比，不能代替实际加速度。
5. **独立验证**：使用另一个数据目录预测关节力矩，与实测及标称模型比较。参数保存为 NPZ。

这是一套完整动态辨识路线。其 README 中的单独重力回归仍是计划项。“从零”也不是无先验：参考实现用 URDF 惯性参数做正则化中心。

## OpenArm 必须适配的内容

| 项目 | 源码情况 | 本项目处理要求 |
| --- | --- | --- |
| 模型 | 默认其他机器人的单臂 URDF | 明确左右七关节、安装变换、夹爪/电机/相机负载 |
| 数据 | 分开的同步位置、速度、力矩 CSV | 从 OpenArm 日志统一导出，验证时间戳与单位 |
| 力矩 | 使用传感器反馈数据 | 当前 `mtau` 来自 `get_torque()`；需确认其标定、方向、滤波和延迟，不能将 `tau_g` 当实测 |
| 滤波 | 主辨识脚本固定窗长 801、阶数 5 | 根据实际采样率和轨迹频率配置；50 Hz 下 801 点约 16 秒，不能照搬 |
| 秩处理 | 非主元 QR 用于条件数分析；实际拟合仍求完整参数 | 使用稳定的秩判定与固定可辨识子空间，不能声称源码已经求出最小基参数 |
| 物理约束 | 主拟合使用无约束线性最小二乘 | 验证正质量、质心范围、惯量物理一致性和非负摩擦/转子惯量 |
| 碰撞 | README 明示关节限位不保证无碰撞 | 优化后还需验证整条轨迹的自碰撞与环境距离 |
| 部署 | 输出完整动态参数 | 对齐 KDL 重力预测；NPZ 不能直接当作现有 YAML 加载 |

原始 CSV 加载器依赖文件顺序和预先同步，不应原样用于存在丢帧或不同时间轴的采数。
